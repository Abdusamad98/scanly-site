Questions fréquentes

Où sont stockés mes documents ? Uniquement sur votre appareil, dans Scanly. Il n’y a ni compte ni synchronisation cloud. Si les sauvegardes de l’appareil sont activées, vos documents y sont inclus comme les données des autres apps.
Comment restaurer Scanly Pro sur un nouvel appareil ? Ouvrez Réglages → Scanly Pro → Restaurer les achats en étant connecté avec le compte Apple utilisé pour l’achat.
Comment annuler mon abonnement ? Ouvrez Réglages → Scanly Pro → Gérer l’abonnement, ou l’app Réglages d’iOS → votre nom → Abonnements. Annulez au moins 24 heures avant la fin de la période en cours.
Pourquoi le texte d’une page n’est-il pas consultable ? Le texte est reconnu sur votre appareil après chaque numérisation. La version gratuite permet de reconnaître 30 pages par mois ; une fois la limite atteinte, la reconnaissance reprend le mois suivant ou avec Scanly Pro. Vous pouvez aussi ouvrir le document et toucher Texte → Reconnaître le texte.
J’ai supprimé un document par erreur. Ouvrez Documents → Suppressions récentes. Les documents y restent pendant 30 jours.
Je ne sais plus comment ouvrir un document verrouillé. Les documents verrouillés s’ouvrent avec Face ID, Touch ID ou le code de votre appareil, c’est-à-dire le même code que celui qui déverrouille votre appareil.
